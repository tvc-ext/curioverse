# CurioVerse roadmap

## Phase 0 — Foundation

- Product vision and child-safety rules
- Local-first architecture
- Flutter design system
- Navigation prototype
- Seed content and deterministic demo state

## Phase 1 — Playable offline MVP

- Avatar and age-band setup
- Visual topic cards
- Quiz engine with explanations
- Three mini-games: patterns, memory, and logic
- Curiosity energy and collectible rewards
- Local progress persistence
- Parent gate and settings
- Accessibility and basic offline tests

## Phase 2 — Creative intelligence

- Guided idea lab
- Safe prompt templates
- Drawing/story/science missions
- AI provider abstraction with hard safety filters
- Non-AI activity fallback
- Parent-visible AI activity history

## Phase 3 — Private friends

- Parent-created friend invite codes
- Fictional identities only
- Small approved circles
- Preset reactions and cooperative challenges
- No free-form chat in the first social release
- Backend threat model and consent lifecycle

## Phase 4 — Content operations

- Signed content packs
- Age-band review workflow
- Educator/parent feedback
- Content quality and bias evaluation
- Privacy-preserving product analytics

## Initial definition of done

The prototype is installable, works without network access, demonstrates six primary destinations, uses no real child data, and passes analysis/tests.
