# CurioVerse

CurioVerse is a safe, local-first mobile learning universe for children—combining short games, visual knowledge cards, quizzes, creativity challenges, and privacy-conscious friend connections.

## Product principles

- Fun before instruction
- Age-band appropriate content
- No real names in the child-facing experience
- Local-first data for the initial release
- No ads or manipulative engagement loops
- Parent-controlled social features
- Small, replayable learning activities

## Initial scope

This repository starts with a Flutter prototype and product/architecture documentation. The first milestone is an offline demo covering Home, Explore, Quiz, Games, Friends, and Profile experiences.

See [docs/ROADMAP.md](docs/ROADMAP.md) for the delivery plan.

## Development

