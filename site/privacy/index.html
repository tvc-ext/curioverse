Privacy Policy

CurioVerse privacy policy

Effective date: 16 August 2026

CurioVerse is designed as a child-friendly, local-first learning app. This policy describes the current implementation of the app and website.

Summary

CurioVerse currently does not provide CurioVerse accounts, a CurioVerse cloud database, ads, purchases, analytics, cookies, trackers, website forms, public chat, or social posting. The app stores the child's explorer profile and learning progress on the device.

Information the app asks the child to choose

During onboarding, CurioVerse asks the child to choose a broad age band and an explorer avatar. The age bands are 6-8, 9-11, and 12-14. The avatar is a playful alias such as Nova Fox, Pixel Panda, Cosmo Cat, or Astro Owl.

The current app does not ask for a real name, exact age, school, phone number, email address, precise location, or account password.

Local storage on the device

CurioVerse uses local app storage through Flutter shared preferences. Current stored values include:

  • Selected broad age band.
  • Selected explorer avatar ID.
  • Curiosity energy score.
  • Completed topic or game IDs.
  • Question history used to avoid repeated quiz questions.
  • Cached public educational content and remote question packs for offline use.

This data is intended to stay on the device unless the operating system, backup settings, or parent-managed device tools copy app data outside the app.

Camera, gallery, and image labeling

The Animal Picture Scanner can ask for camera access or gallery access when the child chooses to take or select a picture. CurioVerse uses image picker functionality to load the selected image into the app.

Current image labeling uses Google ML Kit image labeling on the device. The app does not upload the photo for labeling in the current implementation. After a label is detected, the app may send the detected label text, such as an animal or object name, to Wikipedia to request a public fact summary.

AI image labels can be wrong. CurioVerse shows labels as guesses and encourages comparison with trusted references.

External and public educational content

CurioVerse can request public educational content from third-party public sources. The current implementation includes requests to Wikipedia summary APIs, NASA image search APIs, and a public GitHub-hosted CurioVerse content repository for versioned question packs and game content.

These requests are used to show educational content and cache it locally. Because these are third-party services, network requests may include ordinary technical information such as IP address, device or browser network metadata, request time, requested URL, and user-agent or API user-agent details as part of normal internet operation.

CurioVerse should not be described as transmitting no third-party network data, because public educational content requests are part of the current implementation.

Accounts, backend, and database

The current CurioVerse app has no CurioVerse account system and no CurioVerse cloud database. It does not currently sync a child's profile or progress to a CurioVerse server.

Advertising, analytics, cookies, and tracking

The current CurioVerse app has no ads, ad SDKs, in-app purchases, analytics SDKs, or behavioral tracking features. This static website does not include analytics, cookies, trackers, forms, JavaScript, or a backend.

Children's safety choices

CurioVerse is built around broad age bands, local progress, short learning missions, and parent-friendly controls. The current app avoids collecting direct personal identifiers from children and does not provide public chat or public profile sharing.

Data deletion

The app includes a way to reset the explorer profile, which clears the stored age band, avatar, and learning progress from local app storage. A parent can also remove local app data by using Android app storage controls or uninstalling the app.

Changes to this policy

This policy should be updated before adding accounts, cloud sync, ads, analytics, purchases, friend connections, public sharing, or any new third-party data flow.

Contact

For support and privacy questions, use the support contact path listed in the Google Play listing or the CurioVerse support page.
