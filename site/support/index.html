Support And Contact

Need help with CurioVerse?

This static support page gives help paths without collecting information through a website form.

Quick checks

  • Allow camera permission if the picture scanner does not open.
  • Use a clear, well-lit image for better on-device image labels.
  • Connect to the internet if public learning summaries or remote question packs do not load.
  • If remote content is unavailable, CurioVerse should continue with its built-in offline starter pack.

Contact path

CurioVerse does not use a contact form on this website. For now, use the support option shown in the Google Play listing, or contact the repository owner through the public project page on GitHub.

GitHub project: https://github.com/tvc-ext/curioverse

Privacy questions

For privacy details suitable for Google Play, see the CurioVerse Privacy Policy.
